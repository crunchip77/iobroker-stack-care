# Mitmachen

Dieses Repository ist eine **Diskussionsvorlage** (RFC), kein offizielles ioBroker-Projekt.

## Feedback

- **Kleine Korrekturen** (Tippfehler, Klarheit): Pull Request oder Issue.
- **Inhaltliche Richtungsänderung:** bitte zuerst ein Issue mit Kurzbegründung – dann PR oder Kommentar im Forum-Thread (falls verlinkt).

## Sprache

Dokumente primär **Deutsch**. Englische Kurzfassung ist Backlog (siehe `iobroker-stack-care-github-vorbereitung.md`).

## Was nicht hier hingehört

Keine Secrets, keine produktiven Zugangsdaten, keine privaten Mail-Entwürfe an Maintainer (bleiben außerhalb des Repos).
