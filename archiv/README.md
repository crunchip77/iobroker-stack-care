# Archiv: Entwurf „Stack Care“

Hier liegt der ursprüngliche Entwurf vom November 2026. Er wird nicht mehr weiterverfolgt.

Die Idee waren versionierte Gesamt-Releases („Stack-Releases“) und eine eigene Admin-Seite „Systempflege“. In der [Forum-Diskussion](https://forum.iobroker.net/topic/85889/updates-systempflege-geht-das-für-normalnutzer-einfacher) hat sich gezeigt, dass ein kuratiertes Gesamt-Release nicht zu ioBroker passt, weil die Adapter bewusst unabhängig sind, und dass vieles schon vorhanden ist.

Was davon übrig geblieben ist, steht als konkrete Vorschläge im [README](../README.md).

| Datei | Inhalt |
|-------|--------|
| `iobroker-stack-care-ausarbeitung.md` | Argumentation, Kurzfassung |
| `iobroker-stack-care-konzept.md` | ausführliches Konzept |
| `iobroker-stack-care-review.md` | Sinn, Aufwand, Image-Historie |
| `iobroker-stack-care-admin-mockup.md` | UI-Skizze |
| `examples/` | Beispiel für ein Stack-Manifest |
